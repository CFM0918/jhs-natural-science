# 國一(七年級) 生物3-3《淋巴與免疫》— 教材摘要與重點主題

## 一、本節摘要

淋巴系統包含淋巴、淋巴管與淋巴結,回收組織液並協助防禦。免疫是身體抵抗病原體的防禦機制:皮膚黏膜是第一道防線,白血球能吞噬病原,淋巴球產生抗體對抗特定病原。疫苗可使身體預先產生免疫力。

## 二、4大重點主題

### 主題1：淋巴系統
- 淋巴、淋巴管、淋巴結
- 回收組織液
- 協助防禦

### 主題2：免疫的防線
- 第一道:皮膚與黏膜
- 白血球吞噬病原
- 淋巴球產生抗體

### 主題3：抗體與專一性
- 抗體對抗特定病原
- 具專一性
- 病後可留下記憶

### 主題4：疫苗
- 使身體預先產生免疫
- 含減弱或無害病原成分
- 預防疾病

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 淋巴系統與免疫無關 | 淋巴系統參與免疫防禦 |
| 抗體能對抗所有病原 | 抗體具專一性 |
| 疫苗是治療用藥 | 疫苗是預防用 |
| 皮膚不算免疫 | 皮膚是第一道防線 |

## 四、生活與職場連結（素養導向）
- **打疫苗**：預防疾病
- **傷口紅腫**：免疫反應
- **淋巴結腫**：抵抗感染
