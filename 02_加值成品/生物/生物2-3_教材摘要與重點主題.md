# 國一(七年級) 生物2-3《人體的消化與吸收》— 教材摘要與重點主題

## 一、本節摘要

人體透過消化把大分子食物分解成可吸收的小分子。消化系統包括口、食道、胃、小腸、大腸等。消化酵素(如唾液澱粉酶、胃蛋白酶)分工分解不同養分。小腸是主要吸收場所,其絨毛增大吸收面積。大腸吸收水分並形成糞便。

## 二、4大重點主題

### 主題1：消化的意義
- 把大分子分解成小分子
- 才能被吸收利用
- 分機械與化學消化

### 主題2：消化系統
- 口→食道→胃→小腸→大腸
- 各器官分工
- 附屬:肝、胰

### 主題3：消化酵素
- 唾液澱粉酶分解澱粉
- 胃蛋白酶分解蛋白質
- 酵素分工

### 主題4：吸收
- 小腸是主要吸收場所
- 絨毛增大吸收面積
- 大腸吸收水分

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 胃是主要吸收器官 | 小腸才是主要吸收場所 |
| 消化只是把食物磨碎 | 還包括酵素化學分解 |
| 大腸負責消化養分 | 大腸主要吸收水分 |
| 所有酵素都在胃作用 | 不同酵素在不同器官作用 |

## 四、生活與職場連結（素養導向）
- **細嚼慢嚥**：幫助消化
- **小腸絨毛**：增吸收
- **腸胃保健**：消化健康
