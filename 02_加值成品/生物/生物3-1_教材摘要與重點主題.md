# 國一(七年級) 生物3-1《植物體內的運輸》— 教材摘要與重點主題

## 一、本節摘要

植物有兩種運輸管道:木質部運送根吸收的水分與礦物質,由下往上(靠蒸散作用拉力);韌皮部運送葉子光合作用製造的養分,可雙向運送。維管束由木質部與韌皮部組成,構成植物的運輸系統。

## 二、4大重點主題

### 主題1：木質部
- 運送水分與礦物質
- 方向由根往上
- 靠蒸散拉力

### 主題2：韌皮部
- 運送光合作用養分
- 可雙向運送
- 由葉往各處

### 主題3：維管束
- 木質部+韌皮部
- 植物運輸系統
- 分布於根莖葉

### 主題4：蒸散作用
- 水分由氣孔散失
- 產生拉力向上運水
- 受環境影響

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 木質部運送養分 | 木質部運水分,韌皮部運養分 |
| 植物運輸只有向上 | 韌皮部可雙向運送 |
| 水分靠植物主動抽送 | 主要靠蒸散拉力 |
| 只有莖有維管束 | 根莖葉都有維管束 |

## 四、生活與職場連結（素養導向）
- **樹木輸水**：木質部
- **果實變甜**：養分運輸
- **缺水枯萎**：蒸散失衡
