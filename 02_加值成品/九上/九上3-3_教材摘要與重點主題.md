# 國三上學期 九上3-3《能量的轉換與守恆》— 教材摘要與重點主題

## 一、本節摘要

能量有多種形式:力學能、熱能、光能、電能、化學能、核能等,可互相轉換。能量守恆定律:能量不會憑空產生或消滅,只會由一種形式轉為另一種,總量不變。轉換過程常有部分能量轉為熱能散失,故效率小於100%。

## 二、4大重點主題

### 主題1：能量的形式
- 力學能、熱能、光能
- 電能、化學能、核能
- 可互相轉換

### 主題2：能量轉換
- 一種形式轉為另一種
- 如電能→光能(燈)
- 化學能→力學能(肌肉)

### 主題3：能量守恆定律
- 能量不生不滅
- 只是形式轉換
- 總量不變

### 主題4：效率
- 有用輸出/總輸入
- 常有熱能散失
- 效率小於100%

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 能量會消失 | 能量守恆,只是轉換 |
| 能量轉換效率可達100% | 總有部分散失為熱 |
| 永動機可行 | 違反能量守恆,不可行 |
| 熱能不算能量 | 熱能是能量的一種 |

## 四、生活與職場連結（素養導向）
- **燈泡**：電能轉光熱
- **電池**：化學能轉電能
- **吃飯運動**：化學能轉力學能
