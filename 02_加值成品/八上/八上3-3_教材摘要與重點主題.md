# 國二上學期 八上3-3《聲音的三要素》— 教材摘要與重點主題

## 一、本節摘要

聲音有三要素：響度取決於振幅(振幅大聲音響)、音調取決於頻率(頻率高音調高)、音色取決於波形(不同樂器波形不同)。弦樂器弦越緊越短越細音調越高、管樂器空氣柱越短音調越高、鼓面越小越緊音調越高——這些改變都反映在波形上。

## 二、4大重點主題

### 主題1：響度
- 由振幅決定
- 振幅大→響度大(較大聲)
- 單位分貝dB

### 主題2：音調
- 由頻率決定
- 頻率高→音調高
- 人耳可聽20~20000Hz

### 主題3：音色
- 由波形決定
- 不同樂器波形不同
- 可分辨聲音來源

### 主題4：影響音調的因素
- 弦:越緊、越短、越細→音調越高
- 空氣柱:越短→音調越高
- 鼓:越小、越緊→音調越高

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 聲音越大音調越高 | 響度與音調無關，響度看振幅、音調看頻率 |
| 音色由頻率決定 | 音色由波形決定 |
| 弦越長音調越高 | 弦越短音調才越高 |
| 分貝是音調單位 | 分貝是響度單位 |

## 四、生活與職場連結（素養導向）
- **調吉他**：轉緊弦提高音調
- **辨認人聲**：靠音色分辨
- **噪音分貝**：以dB衡量響度
