# 國二上學期 八上2-3《混合物的分離》— 教材摘要與重點主題

## 一、本節摘要

依成分性質差異可用不同方法分離混合物：過濾分離不溶固體與液體、蒸發結晶取得溶解的固體、蒸餾分離沸點不同的液體、簡易濾紙層析法分離不同色素。選擇方法要看成分的溶解性、沸點等差異。

## 二、4大重點主題

### 主題1：過濾
- 分離不溶固體與液體
- 利用顆粒大小差異
- 濾紙留固體、濾液通過

### 主題2：蒸發與結晶
- 加熱使溶劑蒸發
- 留下溶解的固體
- 如海水曬鹽

### 主題3：蒸餾
- 利用沸點差異
- 加熱汽化再冷凝
- 分離水與溶解物、純化水

### 主題4：簡易濾紙層析法
- 分離混合色素
- 成分移動速率不同而分開
- 不涉及層析原理

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 過濾能分離溶解的鹽 | 過濾不能分離已溶解物，需蒸發 |
| 蒸餾後留在瓶內的是純水 | 蒸餾收集的冷凝液才是純水 |
| 層析要記原理 | 課綱只需操作，不涉原理 |
| 所有混合物都能過濾分離 | 要看是否為不溶固體 |

## 四、生活與職場連結（素養導向）
- **海水曬鹽**：蒸發結晶取鹽
- **淨水器**：過濾去除雜質
- **墨水分析**：層析看色素成分
