# 國二上學期 八上1-1《科學的態度與方法》— 教材摘要與重點主題

## 一、本節摘要

本節認識科學探究的歷程：觀察→提問→假設→設計實驗→蒐集數據→分析→結論，並理解這是可反覆修正的過程。重點在「變因的控制」——分辨操縱變因、應變變因與控制變因，並善用對照組做公平比較。同時建立國際單位制(SI)的概念：長度(公尺m)、質量(公斤kg)、時間(秒s)等基本量，以及由基本量組合而成的導出量。最後學會測量時的估計值與有效數字，養成誠實、客觀、可重複驗證的科學態度。

## 二、4大重點主題

### 主題1：科學方法的歷程
- 觀察→提問→假設→實驗→分析→結論
- 假設是對問題的暫時解答，可被驗證或否證
- 科學結論具暫時性，會隨新證據修正

### 主題2：變因與對照實驗
- 操縱變因：刻意改變的量
- 應變變因：隨之改變、被測量的結果
- 控制變因：保持不變以求公平
- 對照組：作為比較的基準

### 主題3：國際單位制 SI
- 長度—公尺(m)、質量—公斤(kg)、時間—秒(s)
- 溫度—克耳文(K)、電流—安培(A)
- 基本量可組合成導出量(如面積m²、密度kg/m³)

### 主題4：測量、估計值與有效數字
- 讀數要估到最小刻度的下一位
- 估計值是合理估計，不是亂猜
- 有效數字位數反映測量的精密度
- 重複測量取平均可降低隨機誤差

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 科學方法一定照固定順序走完 | 實際研究常反覆修正、來回檢驗，不是死板直線 |
| 假設被推翻代表實驗失敗 | 否證假設同樣是有價值的科學結果 |
| 測量值小數位愈多愈準確 | 超過儀器最小刻度的位數沒有意義 |
| 估計值是隨便猜一個 | 估計值須依最小刻度合理估到下一位 |
| 12cm 和 12.0cm 意義相同 | 12.0cm 精密到 0.1，有效數字不同 |

## 四、生活與職場連結（素養導向）
- **科學新聞判讀**：用變因與對照概念檢視「某食物防癌」報導是否嚴謹
- **料理小實驗**：固定水量與食材，只改火力，比較熟度差異
- **健康量測**：體溫、體重的單位與量測精密度
- **全球接軌**：SI 單位讓各國實驗數據可互相比較
