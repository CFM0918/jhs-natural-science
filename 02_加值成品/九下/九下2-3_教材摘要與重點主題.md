# 國三下學期 九下2-3《電流在磁場中受力》— 教材摘要與重點主題

## 一、本節摘要

通電導線置於磁場中會受力,力的方向與電流方向、磁場方向都有關(可用左手/佛萊明定則判斷)。改變電流或磁場方向,受力方向隨之改變。馬達(電動機)就是利用通電線圈在磁場中受力轉動,把電能轉為動能的裝置。

## 二、4大重點主題

### 主題1：磁場中的受力
- 通電導線在磁場中受力
- 力與電流、磁場方向有關
- 三者互相垂直

### 主題2：受力方向判斷
- 用左手(佛萊明)定則
- 改變電流或磁場方向,力反向
- 電流磁場平行時不受力

### 主題3：馬達原理
- 通電線圈在磁場中受力轉動
- 電能轉為動能
- 需換向裝置持續轉

### 主題4：應用
- 電風扇、洗衣機
- 電動車
- 各種電動機械

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 磁場中導線一定受力 | 電流與磁場平行時不受力 |
| 馬達把動能轉電能 | 馬達把電能轉動能(發電機才相反) |
| 受力方向固定不變 | 隨電流磁場方向改變 |
| 不通電導線也在磁場受力 | 需有電流才受力 |

## 四、生活與職場連結（素養導向）
- **電風扇**：馬達轉動
- **電動車**：馬達驅動
- **洗衣機**：馬達
