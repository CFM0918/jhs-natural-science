# 國三下學期 九下3-1《大氣與天氣要素》— 教材摘要與重點主題

## 一、本節摘要

大氣依溫度變化由下而上分為對流層、平流層等,天氣現象主要發生在對流層。天氣要素包括氣溫、氣壓、濕度、風、雲量與降水等。氣壓是空氣的重量造成,高處氣壓低。課綱刪除氣象觀測及預報的內容(移至國小)。

## 二、4大重點主題

### 主題1：大氣的分層
- 由下而上:對流層、平流層等
- 依溫度變化分層
- 天氣現象主要在對流層

### 主題2：天氣要素
- 氣溫、氣壓、濕度
- 風、雲量、降水
- 綜合構成天氣

### 主題3：氣壓
- 空氣重量造成的壓力
- 高處氣壓較低
- 影響天氣變化

### 主題4：課綱範圍
- 刪除氣象觀測及預報(移國小)
- 重點在大氣結構與要素
- 認識天氣現象

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 天氣現象發生在平流層 | 主要發生在對流層 |
| 高山氣壓比平地高 | 高處氣壓較低 |
| 大氣沒有重量 | 空氣有重量產生氣壓 |
| 氣溫隨高度一直上升 | 對流層內隨高度上升而降 |

## 四、生活與職場連結（素養導向）
- **高山空氣稀薄**：氣壓低
- **氣象報告**：天氣要素
- **濕度計**：測濕度
