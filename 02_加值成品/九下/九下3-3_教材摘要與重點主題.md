# 國三下學期 九下3-3《臺灣的天氣》— 教材摘要與重點主題

## 一、本節摘要

臺灣位於季風氣候區,冬季吹東北季風(較冷乾)、夏季吹西南季風(較熱濕)。春末夏初有梅雨(滯留鋒面),夏秋有颱風帶來強風豪雨。認識臺灣主要天氣型態與災變天氣的成因與防災。

## 二、4大重點主題

### 主題1：季風
- 冬季東北季風(冷乾)
- 夏季西南季風(熱濕)
- 隨季節轉換

### 主題2：梅雨
- 春末夏初
- 滯留鋒面停留
- 連日降雨

### 主題3：颱風
- 夏秋常見
- 低氣壓強烈旋轉
- 帶來強風豪雨

### 主題4：災變天氣與防災
- 颱風、豪雨、寒流
- 可能致災
- 留意預警與防範

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 臺灣夏季吹東北季風 | 夏季吹西南季風 |
| 颱風是高氣壓 | 颱風是強烈低氣壓 |
| 梅雨是短暫陣雨 | 梅雨是滯留鋒面連日降雨 |
| 颱風只有壞處 | 颱風也帶來重要水資源 |

## 四、生活與職場連結（素養導向）
- **颱風假**：防災
- **梅雨季潮濕**：滯留鋒
- **冬季寒流**：東北季風
