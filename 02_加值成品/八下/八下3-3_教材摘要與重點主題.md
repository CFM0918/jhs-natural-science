# 國二下學期 八下3-3《中和與鹽》— 教材摘要與重點主題

## 一、本節摘要

酸與鹼反應生成鹽和水,稱中和反應(H⁺+OH⁻→H₂O)。中和是放熱反應。鹽是酸鹼中和的產物,如食鹽NaCl。pH值表示酸鹼程度(pH<7酸性、=7中性、>7鹼性),本節認識pH意義,不涉及pH計算(移高中),也不涉莫耳濃度稀釋計算。

## 二、4大重點主題

### 主題1：中和反應
- 酸+鹼→鹽+水
- H⁺+OH⁻→H₂O
- 放熱反應

### 主題2：鹽
- 中和反應的產物
- 如NaCl、Na₂SO₄
- 多為離子化合物

### 主題3：pH值
- 表示酸鹼程度
- pH<7酸、=7中、>7鹼
- 課綱不涉pH計算

### 主題4：生活應用
- 胃藥中和胃酸
- 石灰中和酸性土壤
- 牙膏中和口腔酸

## 三、常見迷思與教學提醒

| 迷思 | 正確觀念 |
|---|---|
| 中和後一定是中性 | 視酸鹼強弱與量,不一定恰中性 |
| 鹽只有食鹽 | 鹽是一類化合物,種類很多 |
| pH越大越酸 | pH越大越鹼 |
| 中和是吸熱反應 | 中和是放熱反應 |

## 四、生活與職場連結（素養導向）
- **胃藥**：中和過多胃酸
- **土壤改良**：石灰中和酸
- **蜂螫塗鹼**：中和酸性
